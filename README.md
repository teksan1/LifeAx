# LifeAx

LifeAx is a personal life-governance Android application designed to support addiction recovery, financial discipline, and daily structure through adaptive AI guidance.

This repository is in early development and not intended for public distribution yet.

## Status
- Android app scaffold complete
- Jetpack Compose UI
- Local-first data philosophy
- Behavioral engines under development

## Build
- Android
- Kotlin
- Jetpack Compose

## Privacy
All user data is stored locally and never shared.
