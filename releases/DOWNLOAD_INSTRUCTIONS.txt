📱 QUICK START GUIDE

1. DOWNLOAD
   - Download the APK file: lifeax-v1.0.0-release.apk
   - File size: ~38MB
   - Requires Android 5.0 or higher

2. ENABLE INSTALLATION
   - Go to Settings > Security > Unknown Sources
   - Toggle ON to allow installation from unknown sources

3. INSTALL
   - Open the downloaded APK file
   - Tap "Install"
   - Wait for installation (30-60 seconds)
   - Tap "Open" to launch

4. FIRST LAUNCH
   - Sign in with your credentials
   - Grant permissions when prompted
   - Start using LifeAx!

================================================================================
                         TROUBLESHOOTING
================================================================================

Installation Issues:
- "Unknown app" warning → Tap "Install anyway"
- "Insufficient storage" → Free up 100MB+ space
- "App not compatible" → Update Android to 5.0+

Runtime Issues:
- App crashes → Clear cache in Settings > Apps > LifeAx
- Features not working → Check internet connection
- Slow performance → Close background apps
