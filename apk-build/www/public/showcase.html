System Architecture

LifeAx is built on a modern, scalable architecture with clear separation of concerns and type-safe communication.

Database Schema

  • Users: Authentication and profile management
  • Conversations: Chat history and metadata
  • Messages: Individual chat messages with roles
  • Tasks: Task items with priorities and due dates
  • Calendar Events: Scheduled events with times and locations
  • Notifications: User alerts and reminders
  • Habits: Habit tracking with frequency
  • Recommendations: AI-generated insights

API Procedures (tRPC)

  • Chat: createConversation, sendMessage, getMessages
  • Tasks: create, list, update, delete
  • Calendar: createEvent, getEvents, updateEvent, deleteEvent
  • Notifications: list, markAsRead
  • Recommendations: generate, list
  • Habits: create, list
